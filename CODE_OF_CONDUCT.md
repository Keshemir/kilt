# Code of conduct

kilt is a small project, and we want everyone to feel welcome here, beginners too.

**Please:**

- be kind and patient;
- talk about the code, not about the person;
- accept that people have different opinions and different levels of experience;
- help newcomers.

**Not allowed:**

- insults, threats and harassment;
- jokes or comments about anyone's gender, race, religion, body, age or origin;
- sharing other people's private information.

If someone breaks these rules, the maintainers can remove comments, close issues or block the person from the project.

To report a problem, open a private report on GitHub (Security → Report a vulnerability) and write "Code of conduct" in the title. Only the maintainers can see it.
